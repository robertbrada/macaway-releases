# MacAway downloads

MacAway is a menu bar app that locks your Mac when you walk away from it, by following an
iPhone or Apple Watch over Bluetooth. There is no server, no account, and nothing to install
on the phone.

This repo carries the notarised release archives and nothing else. The app's source is not
public.

Every archive hangs off the single release tagged [`archives`](../../releases/tag/archives).
The app updates itself from `https://macaway.app/appcast.xml`.

Downloads and documentation: https://macaway.app
